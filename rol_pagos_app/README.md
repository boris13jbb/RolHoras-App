# rol_pagos_app

Aplicación Flutter para registrar horas/pagos y sincronizar roles de pago (PDF) desde Gmail.

## Estado
- App Android funcional en modo debug.
- Historial: importar PDF local, procesar, ver PDF (visor externo) y eliminar.
- Gmail: conexión OAuth + sync por remitente configurable.
